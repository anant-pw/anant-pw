## Projects

### [keyword_excel_framework](https://github.com/anant-pw/keyword_excel_framework)

A keyword-driven test framework in Python. Test cases are written as spreadsheet rows and executed through Playwright. It has per-case browser contexts, saved-session reuse, process-level parallel runs, API and UI steps in one context, JSON-schema checks, and an HTML report with run history. 140 unit tests. Personal project, public demo sites only.

### [qa-agentic-rag](https://github.com/anant-pw/qa-agentic-rag) (personal project, exploration)

Question answering over bug reports and test cases, running locally. It uses hybrid search (BM25 plus vectors), deterministic routes for questions that do not need a model, and an evaluation harness scored against database ground truth. Results and known limits are in its README. Built with AI coding assistance as a way to learn the stack.

### [VerdictAI](https://github.com/anant-pw/VerdictAI) (personal project, exploration)

YAML-defined evaluation suites for LLM output: heuristic checks plus two LLM judges.

### [testAtlas](https://github.com/anant-pw/testAtlas) (personal project)

One dashboard over several test-management and defect trackers, through a common schema.
